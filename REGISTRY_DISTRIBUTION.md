# Registry distribution boundary

This repository is a BTG-controlled clean-room/conformance baseline for ENTITY. Registry publication is intended to make the verifier easier to discover and run; it does not convert BTG-controlled evidence into independent third-party validation.

The published package must preserve the existing sealed campaign inputs, expected classifications, hashes, and fail-closed behavior. Package metadata, installation UX, and registry discoverability may change without changing protocol campaign semantics.

For independent evidence, use an independently controlled repository and document the exact public specification/test material consulted.
